# Vanppo Picks

## How do I install these formulae?

`brew install vanppo/picks/<formula>`

Or `brew tap vanppo/picks` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "vanppo/picks"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
